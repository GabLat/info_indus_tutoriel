******************************
Explications du projet
******************************

Ce tutoriel explique comment commander un pantographe à l'aide de ROS2.

Dans un premier temps le matériel requis pour ce tutoriel sera présenté.  
Dans un second temps l'installation des logiciels sera expliquée.  
La troisième partie de ce tutoriel est consacrée aux réalisations effectuées dans ce tutoriel.
