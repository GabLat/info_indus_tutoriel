Création du modèle URDF

La description d’un modèle URDF s’appuie sur des balises. Ces balises permettent de décrire les différents éléments du robot. Comme expliqué dans la section Pantographe, nous utilisons les fichiers STEP pour créer la géométrie de chaque corps du pantographe. Cette description s’inscrit dans la balise <visual> qui permet de décrire la géométrie du corps. La balise <collision> permet de décrire la géométrie du corps pour les calculs de collision. Afin de simplifier les calculs nous utilisons un maillage en format DAE correspondant à un volume simple qui contient le corps. Ceci permet en plus de simplifier le calcul d’assurer que le robot ne rentre pas en collision car son enveloppe sera plus grande que sa géométrie réelle.

Les fichiers ont été regroupés dans un fichier URDF.

<?xml version="1.0"?>

<!-- Fixation du robot à 'base_link' -->
<link name="map"/>

<!-- Base Link -->
<link name="base">
    <visual>

        <mesh filename="base.dae" scale="1 1 1" />
    </geometry>
    <origin xyz="0 0 0.025"/>
    </visual>
    <inertial>
    <mass value="1" />
    <origin xyz="0 0 0.025" rpy="0 0 0" />
    <inertia ixx="1" ixy="0" ixz="0" iyy="1" iyz="0" izz="1" />
    </inertial>
    <collision>
    <geometry>

    <origin xyz="0 0 0.025"/>
    </collision>
</link>

<joint name="base2world" type="fixed">
    <parent link="map"/>
    <child link="base"/>
</joint>
